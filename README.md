# مركز TM لصيانة الأجهزة المنزلية — النسخة المطوّرة

## تشغيل محلي على Windows
1. فك ضغط الملف إلى مجلد عادي.
2. ثبّت Python 3 إن لم يكن مثبتًا (لا يحتاج المشروع إلى مكتبات Python إضافية).
3. انقر مرتين على `run_local.bat`، أو افتح Terminal داخل المجلد وشغّل: `py -3 server.py`.
4. افتح `http://127.0.0.1:8080`. أوقف الخادم باستخدام `Ctrl+C`.

يمكن رفع الملفات نفسها إلى استضافة Apache تدعم `.htaccess`؛ الملف يعيد توجيه مسارات التطبيق غير الموجودة إلى `index.html`. إذا كانت الاستضافة لا تدعم rewrite، فعّل قاعدة SPA مكافئة حتى تعمل الروابط العميقة عند تحديث الصفحة.

## الأصول والتبعيات
- صور الأقسام والرسوم التوضيحية داخل `assets/` ومحلية.
- يستخدم الموقع أيقونات Font Awesome من CDN اختياري؛ يلزم اتصال إنترنت لعرض مجموعة الأيقونات بالكامل. يعمل المحتوى الأساسي من دونه مع تراجع بصري لبعض الأيقونات. تم إزالة خط Google الخارجي والاعتماد على خطوط النظام لتقليل التبعيات.
- لا يوجد `package.json` أو خطوة بناء؛ المشروع HTML/CSS/JavaScript ثابت.

## حدود المعلومات
تجنّبت النسخة المطوّرة عرض تقييمات/إحصاءات غير موثقة أو ادعاءات اعتماد من الشركات المصنّعة أو ضمانات ومدد وصول ثابتة. أسماء الماركات للتعريف باختيار الماركة ولا تدل على شراكة رسمية. يجب على صاحب المركز تأكيد نطاق الخدمة، وساعات العمل، وسياسة الضمان، وتوفر قطع الغيار قبل نشر أي معلومات تفصيلية عنها.

## الملفات الرئيسية
- `index.html`: الصفحات والأقسام والبيانات الوصفية.
- `style.css`: تنسيق الواجهة والاستجابة للشاشات.
- `script.js`: التنقل، اللغة، البحث، الأسئلة، التفاعل، وفتح واتساب من النموذج.
- `assets/`: شعار TM ورسوم محلية للأجهزة والخدمات.
- `server.py` و`run_local.bat`: تشغيل محلي مع دعم مسارات التطبيق.
- `.htaccess`, `robots.txt`, `sitemap.xml`: إعدادات نشر وفهرسة الويب.

راجع `RUN_GUIDE.md` للتعليمات التفصيلية و`AUDIT_REPORT.md` لنتائج الفحص والقيود التي لم يُختبر بعضها في متصفح حقيقي.
